Proxy

If a provider is unavailable on your network, route QTranslate through the same working Windows system proxy / VPN route as your browser, then restart QTranslate.

Safety and licensing

Prefer a clean original QuestSoft executable plus transparent service/configuration files. Do not add unknown modified binaries to antivirus exclusions. New repository releases should not redistribute modified QuestSoft executables or non-original QuestSoft installers without permission.
