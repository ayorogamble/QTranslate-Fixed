FAQ

Does QTranslate work on macOS?

Yes, this repository documents a native community macOS build.

How do I install it?

Download the DMG from GitHub Releases, drag QTranslate into Applications, then grant Accessibility permission.

Where is the OpenAI key stored?

In macOS Keychain.

Is this official?

No. This is an unofficial community project.
