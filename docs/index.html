English setup guide

  1. Download and run the Windows installer, then start QTranslate.
  2. Find its icon in the Windows tray; use the arrow near the clock if it is hidden.
  3. Right-click the icon and enable Mouse mode.
  4. Open Settings → Hotkeys and assign this recommended preset.
ActionHotkey
Show a translation popupCtrl + Q
Replace selected text with translationCtrl + W
Switch the keyboard layout of selected textCtrl + D

Select text and press Ctrl + Q to view its translation without replacing the source. Use Ctrl + A first if you need to select everything in the current field.

In an editable field, select your text and press Ctrl + W to replace it with a translation. Review it before sending. If you typed with the wrong keyboard layout, select the text and use Ctrl + D.

These are custom shortcuts to assign in Settings, not a claim about the app's default bindings.

DeepL, v2rayN and System Proxy

In the author's tested configuration, Google Translate and Yandex Translate worked without a VPN. Service availability can vary by network. If DeepL does not respond, configure your route:

  1. Import a working profile into v2rayN and connect.
  2. Change Clear system proxy to Set system proxy in v2rayN.
  3. In QTranslate, open Settings → Proxy server → Use system proxy settings.
  4. Fully exit QTranslate from its tray icon and start it again, then test DeepL.

If your VPN already routes Windows traffic through TUN or a full tunnel, an additional system proxy may not be necessary.

Importing an existing VPN configuration

Use the import option for your provider's profile or subscription. If only another client's configuration is available, compare its protocol and connection parameters with the v2rayN custom configuration fields. You can ask an assistant to explain the mapping using a redacted example. Keep passwords, private keys and subscription URLs private.

Troubleshooting

  1. Check whether the translation service opens in your browser.
  2. Check both v2rayN's system proxy and QTranslate's proxy setting.
  3. Fully restart QTranslate.
  4. Try another VPN server or exit IP.
  5. Check Releases for an updated build.

Optional browser proxy control: Proxy SwitchyOmega 3 / ZeroOmega. It is not required for QTranslate.

Русская инструкция

  1. Скачайте и запустите установщик, затем откройте QTranslate.
  2. Найдите значок программы в трее Windows. Если он скрыт, нажмите стрелку рядом с часами.
  3. Нажмите правой кнопкой по значку и включите Режим мыши.
  4. Откройте Настройки → Горячие клавиши и назначьте сочетания ниже.
ДействиеКлавиши
Показать всплывающее окно переводаCtrl + Q
Заменить выделенный текст переводомCtrl + W
Переключить раскладку выделенного текстаCtrl + D

Выделите текст и нажмите Ctrl + Q, чтобы посмотреть перевод, сохранив оригинал. Для выделения всего текста в текущем поле сначала нажмите Ctrl + A.

В редактируемом поле выделите текст и нажмите Ctrl + W для замены переводом. Перед отправкой проверьте результат. Если текст набран в неправильной раскладке, выделите его и нажмите Ctrl + D.

Настройка DeepL через v2rayN

В проверенной автором конфигурации Google Translate и Yandex Translate работали без VPN. Доступность зависит от сети. Если DeepL не отвечает:

  1. Импортируйте рабочий профиль в v2rayN и подключитесь.
  2. Вместо Очистить системный прокси выберите Установить системный прокси / Set system proxy.
  3. В QTranslate откройте Настройки → Прокси-сервер → Использовать системные настройки прокси.
  4. Полностью закройте QTranslate через значок в трее и запустите заново.
  5. Проверьте перевод через DeepL.

Если VPN уже направляет трафик Windows через TUN или полный туннель, отдельно включать системный прокси может не потребоваться.

Если нет готового профиля v2rayN

Импортируйте профиль или подписку своего провайдера. Если есть только конфигурация другого клиента, сопоставьте протокол и параметры подключения с полями пользовательской конфигурации v2rayN. Можно попросить нейросеть объяснить перенос на примере с замаскированными секретами. Не публикуйте пароли, приватные ключи и ссылки на подписку.

Если перевод перестал работать

  1. Проверьте, открывается ли сервис перевода в браузере.
  2. Проверьте системный прокси в v2rayN и настройку прокси в QTranslate.
  3. Полностью перезапустите QTranslate.
  4. Попробуйте другой VPN-сервер или выходной IP.
  5. Проверьте обновления в Releases.

Для отдельного управления прокси в браузере можно использовать Proxy SwitchyOmega 3 / ZeroOmega. Для самого QTranslate расширение не требуется.
