QTranslate setup

  1. Install QTranslate Fixed v1.1.0.
  2. Find the QTranslate icon in the Windows tray.
  3. Right-click it and enable Mouse mode.
  4. Open Settings → Hotkeys.
ActionRecommended hotkey
Show popup windowCtrl + Q
Replace selected text with translationCtrl + W
Switch keyboard layout of selected textCtrl + D

DeepL and v2rayN

In the author's tested setup, Google Translate and Yandex Translate work without a VPN. If DeepL does not respond on your network:

  1. Connect to a working profile in v2rayN.
  2. Select Set system proxy.
  3. Open QTranslate Settings.
  4. Open Proxy server.
  5. Select Use system proxy settings.
  6. Restart QTranslate completely.

Русская инструкция

Ctrl + Q показывает перевод выделенного текста.

Ctrl + W заменяет выделенный текст переводом.

Ctrl + D переключает раскладку выделенного текста.

Для DeepL при необходимости включите в v2rayN Установить системный прокси, затем в QTranslate выберите Использовать системные настройки прокси.
