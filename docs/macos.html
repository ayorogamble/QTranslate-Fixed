Install

  1. Download the DMG from GitHub Releases.
  2. Open it and drag QTranslate into Applications.
  3. Launch QTranslate.
  4. Grant Accessibility permission in System Settings -> Privacy & Security -> Accessibility.

If an unsigned build is blocked, verify its SHA256 checksum, then use Finder Open or Open Anyway in Privacy & Security. Do not disable Gatekeeper globally.

OpenAI / ChatGPT

Open QTranslate -> Settings -> OpenAI (ChatGPT), enter your own API key and choose a model. The key is stored in macOS Keychain. OpenAI API billing is separate from a ChatGPT subscription.

Proxy and VPN

Enable Use macOS system proxy when a provider needs to follow the same proxy route as your browser. A full-tunnel VPN may not need a separate proxy.

Security

Never publish API keys in issues, screenshots or logs. Verify release checksums before approving an unsigned build.
