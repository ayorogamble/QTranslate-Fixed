# Changelog

All notable changes to QTranslate Fixed are documented here.

## v1.0.0

Initial public release.

### Fixed

- Updated Google Translate integration.
- Reworked DeepL integration for the current anonymous client endpoint.
- Added a ready-to-use Windows installer.

### Documentation

- Added English and Russian installation instructions.
- Added v2rayN System Proxy setup instructions.
- Added optional ZeroOmega browser proxy instructions.

### Known limitations

- Google and DeepL use unofficial client/web endpoints and may require future updates.
- Some networks or regions may require VPN or proxy routing.
