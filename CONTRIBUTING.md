# Contributing

Contributions are welcome, especially fixes for translation services that stop working after upstream changes.

## Useful contributions

- Updated QTranslate `Service.js` integrations.
- Reproducible fixes for Google Translate or DeepL failures.
- Better proxy / VPN compatibility instructions.
- Installer fixes.
- Documentation improvements and translations.

## Bug reports

Use the repository bug report template and include:

- QTranslate Fixed version.
- Affected service.
- Exact error message.
- Source and target language.
- VPN / proxy mode.
- Whether the same service works in your browser on the same connection.

## Pull requests

Keep changes focused and explain what upstream behavior changed and why the fix is needed. Avoid adding API keys, cookies, access tokens, personal configuration, or other secrets to commits.
