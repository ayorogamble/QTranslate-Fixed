# QTranslate Fixed for Windows - Guide

## Recommended workflow

1. Install the original QTranslate application from a source you trust.
2. Apply only the community service/configuration files that you understand and have reviewed.
3. Start QTranslate and enable Mouse mode if you use it.
4. Configure hotkeys.

Recommended preset:

| Action | Hotkey |
|---|---|
| Show popup translation | `Ctrl + Q` |
| Translate and replace selected text | `Ctrl + W` |
| Fix keyboard layout | `Ctrl + D` |

## Proxy

If a translation provider is unavailable on your network:

1. Connect your VPN / proxy.
2. Enable the Windows system proxy if your VPN client requires it.
3. Open QTranslate -> Proxy server.
4. Select **Use system proxy settings**.
5. Restart QTranslate completely.

## Security

Do not add unknown modified executables to Defender exclusions merely to suppress a detection. Prefer a clean original executable and transparent service/configuration files.
